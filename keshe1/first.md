# 医疗健康管理系统

## 项目概述

医疗健康管理系统是一个基于Spring Boot开发的多角色医疗管理平台，支持患者、医生和管理员三种用户类型，提供完整的医疗健康服务管理功能。

## 技术栈

- **后端框架**: Spring Boot 2.7.18
- **安全框架**: Spring Security
- **数据访问**: MyBatis-Plus
- **前端模板**: Thymeleaf
- **前端框架**: Bootstrap 5, Font Awesome, Chart.js
- **数据库**: MySQL 8.0
- **构建工具**: Maven 3.9.12

## 系统架构

### 用户角色
- **患者**: 可以注册账号，管理个人信息，查看病历，预约挂号
- **医生**: 由管理员分配账号，管理患者病历，查看预约，处理诊断
- **管理员**: 管理系统用户，科室信息，系统配置

### 功能模块

#### 患者功能
- 个人信息管理
- 电子病历查看
- 诊断记录查询
- 检查报告查询
- 用药历史查询
- 预约挂号管理
- 健康档案管理
- AI健康助手对话

#### 医生功能
- 医生信息管理
- 患者管理
- 病历管理
- 预约管理
- 候诊队列管理
- AI医疗助手对话

#### 管理员功能
- 患者管理
- 医生管理
- 科室管理
- 系统管理
- 数据统计分析
- AI管理助手对话

## 数据库设计

### 主要数据表
- **user**: 用户基础信息表
- **patient**: 患者信息表
- **doctor**: 医生信息表
- **appointment**: 预约信息表
- **medical_record**: 病历信息表
- **diagnosis**: 诊断信息表
- **examination**: 检查信息表
- **medication**: 用药信息表
- **department**: 科室信息表
- **hospital**: 医院信息表

## 安全特性

- **密码加密**: 使用BCrypt进行密码加密存储
- **身份认证**: 基于角色的访问控制
- **登录处理**: 自定义认证成功处理器，支持多角色自动跳转
- **会话管理**: 安全的会话管理机制

## 界面特色

### 统一设计
- 三种用户类型使用统一的界面布局结构
- 患者和医生界面使用浅蓝色主题
- 管理员界面使用白色主题，深灰色边框

### 功能界面
- **侧边栏导航**: 可折叠的多级菜单导航
- **卡片式布局**: 清晰的信息展示
- **数据可视化**: Chart.js图表展示健康数据
- **AI助手**: 底部固定AI对话窗口
- **响应式设计**: 适配不同屏幕尺寸

## 部署说明

### 环境要求
- Java 8+
- Maven 3.5+
- MySQL 8.0+

### 启动步骤
1. 克隆项目代码
2. 配置数据库连接信息
3. 执行数据库初始化脚本
4. 运行 `mvn spring-boot:run`
5. 访问 `http://localhost:8080`
